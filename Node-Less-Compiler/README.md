# LESS Compiler

**🇬🇧 English** | [🇩🇪 Deutsch](README.de.md)

A reusable Node.js command-line tool for compiling LESS files into regular `.css` and minified `.min.css` files. Source and destination directories are passed as arguments; **no project-specific paths are hard-coded**.

## Features

- Recursively compile `.less` files and retain their relative directory structure.
- Generate both `.css` and `.min.css` using Less and clean-css.
- Ignore common underscore-prefixed LESS partials by default (override with `--include-partials`).
- Optionally disable minification with `--no-minify`.
- Safely remove stale outputs **only** with `--clean`, using a manifest of files previously generated by this tool.
- Display progress and return a nonzero exit code on errors.

## Requirements and installation

- Node.js 18 or newer (ES modules)
- npm

Copy `less-compiler.js` and `package.json` into a directory, then install dependencies in that directory:

```bash
npm install
```

If you already have a Node.js project, you can instead install `less` and `clean-css` and ensure the `.js` script runs in an ES-module context (`"type": "module"` in `package.json`).

## Usage

From the directory containing the script:

```bash
node less-compiler.js --src ./assets/less --dest ./public/css
```

Or use positional paths:

```bash
node less-compiler.js ./assets/less ./public/css
```

Relative paths are resolved against the **current working directory**, not the script's directory. Absolute paths are supported.

### Options

| Option               | Description                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `--src <directory>`  | Required source directory containing LESS files.                                                    |
| `--dest <directory>` | Required destination directory. Created if missing.                                                 |
| `--no-minify`        | Generate `.css` files only.                                                                         |
| `--include-partials` | Also compile `.less` filenames beginning with `_`.                                                  |
| `--clean`            | Remove stale outputs recorded in previous manifests; remove empty directories generated by cleanup. |
| `-h`, `--help`       | Display help.                                                                                       |

Use either both named directory options or both positional directory arguments; do not mix the two styles.

### Example

Input:

```text
assets/less/
├── main.less
├── _colors.less
└── admin/
    └── dashboard.less
```

Command:

```bash
node less-compiler.js --src assets/less --dest public/css
```

Output:

```text
public/css/
├── .less-compiler-manifest.json
├── main.css
├── main.min.css
└── admin/
    ├── dashboard.css
    └── dashboard.min.css
```

`_colors.less` is available for `@import` statements, but is not compiled separately by default.

## Cleanup and safety

By default, the tool does **not delete** previous output files. After successful compilation, it saves a file list in `.less-compiler-manifest.json` in the destination directory. If a source file is subsequently deleted or `--no-minify` is used, old generated CSS may remain until you run:

```bash
node less-compiler.js --src assets/less --dest public/css --clean
```

`--clean` deletes only stale output paths recorded by prior executions of this tool; other `.css` files are not swept from the destination directory. **Do not manually edit generated files:** rerunning compilation overwrites matching output filenames. If an output file is replaced by another file at the same tracked path, `--clean` can still delete it when it becomes stale. Only use a dedicated output directory and keep the manifest with it.

## Notes

- The tool requires `less` and `clean-css` installed and is not a standalone native executable.
- Symbolic links in the LESS source tree are not followed.
- Existing CSS files sharing the same path as generated outputs will be overwritten.
- No watch mode is included.
